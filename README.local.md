# 智慧食堂系统（本地应用）

## 1) 安装依赖

```bash
npm install
```

## 2) 启动本地应用

```bash
npm run local
```

启动后访问：

- 本机地址：http://localhost:3000
- 局域网地址：http://0.0.0.0:3000

## 3) 快速测试流程

### 管理方登录并上传菜品
1. 首页点击 **管理方登录**。
2. 输入用户名和密码（新账号会自动注册）。
3. 进入管理页后填写 **时间 / 地点 / 菜品**。
4. 点击 **上传菜品**。

### 用户登录并提建议
1. 首页点击 **用户登录**。
2. 输入用户名和密码（新账号会自动注册）。
3. 登录后进入菜品页，查看管理方上传菜品。
4. 在公开建议区填写建议并提交。

### 游客浏览
1. 首页点击 **浏览（游客模式）**。
2. 可直接查看菜品。
3. 若提交建议，系统会跳转到用户登录弹窗。

## 4) 默认账号

- 默认管理员：`admin`
- 默认密码：`123456`

> 数据保存在浏览器 `localStorage`，刷新页面不会丢失；更换浏览器或清理缓存会清空。
